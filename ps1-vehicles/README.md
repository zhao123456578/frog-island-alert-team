## 使用提示

PS1 画风的关键不只是低面数，还要配点过滤（nearest / Point）贴图、低分辨率纹理、顶点色烘焙光照、关闭平滑着色。以上素材是建模底子，风格渲染需在引擎里另配 PSX shader。

注意：ggbot 包各车之间比例不统一，用前需手动缩放；作者声明与授权详见各包内 README / License 文件。
