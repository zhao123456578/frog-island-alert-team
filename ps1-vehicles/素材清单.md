# PS1 / PSX 风格车辆模型素材

下载于 2026-11-20，全部来自 OpenGameArt，均为 CC0（可商用、免署名）。
itch.io 直连不通，所以走了 OpenGameArt 镜像源，内容一致。

## 1. ggbot_psx_style_cars — 最纯粹的 PS1 风味 ⭐

- 来源：https://opengameart.org/content/psx-style-cars （原作者 ggbot.itch.io）
- 8 辆车：5门旅行车 / 4门轿车 / 3门两厢 / 小巴 / 轿车(警车+出租) / 烧毁残骸 / 1920年代老车 / 厢式货车
- 312–476 tris，128×128 像素贴图，多种车身配色 + 积雪/脏污版本
- 格式：.blend / .obj / .mtl / .png，另附 15 个音效（引擎/开门/喇叭等）
- 注意：作者声明各车之间比例不统一，用前需手动缩放

## 2. soviet_lowpoly_vehicles — 苏式像素风车辆 ⭐

- 来源：https://opengameart.org/content/pack-of-extremly-low-poly-soviet-vehicles-in-pixel-art-style
- 车型：拉达 2101/2105/2106（多配色+警车）、UAZ-469 越野、UAZ-452 面包（含警车/救护）、LiAZ-677 公交（车门动画）、KTM-5 有轨电车（车门动画）
- 极低面数 + 像素贴图，后苏联废土氛围拉满，适合恐怖/生存题材
- 格式：.obj / .mtl / .png

## 3. rgsdev_vehicles_pack — 车型最全

- 来源：https://opengameart.org/content/free-low-poly-vehicles-pack
- 20 种车：4 种警车、肌肉车、跑车、敞篷、轿车、两厢、皮卡、SUV、面包、救护、大脚怪、出租、卡车、拖挂卡车、公交、消防车、豪华轿车
- 车轮分离，颜色按材质区分，方便换色
- 格式：单个 All vehicles.fbx（约 1 MB）

## 4. mehrasaur_vehicle_pack — 粘土素模

- 来源：https://opengameart.org/content/3d-vehicles-pack
- 14 个模型：自行车、公交、4 车、2 越野、5 卡车
- 无贴图/UV，纯 clay model，适合自己重做 PS1 风格贴图
- 格式：.blend / .fbx / .obj + .mtl，三种格式齐全

## 5. kenney_car_kit — 通用性最强

- 来源：https://opengameart.org/content/car-kit （Kenney.nl）
- 45+ 模型：轿车、面包、救护、消防、警车等，8 种独立车轮，还有车辆爆炸碎片
- 优化低模，Unity/Unreal/Godot 通用
- 格式：FBX / OBJ / glTF 分开提供

## 附：quaternius_lowpoly_car_pack

只有 5 张车的预览 PNG，无模型文件，可作配色参考。

---

**使用提示**：PS1 画风的关键不只是低面数，还要配点过滤（nearest/Point）贴图、低分辨率纹理、顶点色烘焙光照、关闭平滑着色。以上素材是建模底子，风格渲染需在引擎里另配 PSX shader。
