# PS1/PSX 追逐游戏 · 建模素材清单

> 需求来源：双路线「下班回家」恐怖追逐（Roblox《Do Not Stop》风格 + PS1 画风）
> - **好结局线**：城镇路，分叉路口有个「孙笑川」挡路 → 撞死他正常回家
> - **坏结局线**：黑漆漆的森林路（俄罗斯远东那种），没有孙笑川 → 被一群孙笑川一直追 → 恐怖事件 → 闭眼结束
> - **镜头**：追逐时只能看到身后追你的人
> - **天堂分支**：停车后画面变白 → 天堂图标 → 链接「回家的路」→ 点开是奶娃指着你大笑
>
> 整理日期：2026-11-21。全部为 itch.io 上 **PSX (PlayStation) / PS1 / Low-poly** 标签素材，标注了价格与是否需登录。
> 多数「Free」素材可直接点 Download Now 下载、**无需登录**；标 `$` 的为付费（会要求登录付款），仅作备选。

## 渲染提示（PS1 画风落地）

1. 贴图用 **Nearest / Point 无过滤**，关 mipmap，保留硬边像素感。
2. 顶点抖动（vertex snapping）+ 低分辨率渲染（如 320×240）再放大。
3. 双面渲染：树干/树叶的面片要 `DoubleSide`。
4. 模型统一 2m 网格对齐（heyheythere 那套都是 2m grid），拼接不漏缝。
5. 追逐镜头只渲染身后追兵 + 前方路，配合雾效藏掉远处加载。
