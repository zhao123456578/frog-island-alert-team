## 视觉：纸片效果

- **2D 广告牌**：`PlaneGeometry` 只绕 Y 轴转向相机，永远正对玩家；不做俯仰/翻滚，人始终直立。
- **非 3D**：`MeshBasicMaterial` 不受光照影响，只有抠像照片本身的明暗；硬边 `alphaTest 0.42`，保留剪纸边缘。
- **纸片厚度**：背后叠一张同样的轮廓网格，用只取 alpha 的 ShaderMaterial 填深色（1.018× / 1.009×，锚点在脚底）→ 侧边约 5mm、头顶约 1.5cm 的深色纸边；0/40/70/100 只带极轻的暖色偏移，不再使用米白描边。
- **去边**：图集打包时把半透明/透明像素的 RGB 换成最近实心像素的颜色（alpha 不变），清掉绿幕反解残留的洋红边与白边。
- **落地感**：脚下一张径向渐变软阴影 + 一圈细光环（颜色跟随愤怒值）。
- **纸的呼吸**：整体轻微摆动（rotation.z / x）、行走时上下 2cm 抖动、0.35% 纵向呼吸；不改变姿态骨骼（源素材是抱臂站立微晃）。
- **动画**：110 帧 @ 15fps 循环（7.33s）；追逐时 1.28× 播放速度。
- **高度**：1.78m；宽 0.61m（按 165:479 原比例）。

## 愤怒值与状态机

| 愤怒值 | 速度倍率 | 实际速度 | 行为 |
|---|---|---|---|
| **0** | 0.80× | 2.40 m/s | 沿固定矩形路线巡逻；无视玩家，不触发追逐 |
| **40** | 0.90× | 2.70 m/s | 寻找玩家并追逐；**玩家倒地 → 丢失目标 → 随机行走** |
| **70** | 1.00× | 3.00 m/s | 寻找玩家并追逐；**倒地照样抓**；只有**丢失视野**才随机行走 |
| **100** | 1.145× | 3.435 m/s | 无限制追逐；隔墙锁定，永不丢失，倒地也抓 |

速度是**玩家速度的倍率**（测试页玩家固定 3.00 m/s）。接主游戏时把 `PLAYER_SPEED` 换成主角实际速度即可，倍率不动。

### 状态

- `PATROL` 巡逻：四点矩形路线，到点转向下一段。
- `SEEK` 寻找：A* 前往「最后目击点」；到达后原地扫视 2.6s，仍没看到 → `WANDER`。
- `CHASE` 追逐：看见玩家即锁定；每 0.42s 重算路径，2.6m 内且视线通畅时直接贴脸。
- `WANDER` 游荡：随机取一个可达点走过去，停 0.9–2.7s 再换点；期间看见玩家会重新追（40 级玩家仍倒地时除外）。
- `GRAB` 抓住：接触 0.95m 且满足等级条件 → 冻结 + 红色覆盖层，按 `R` 或按钮重来。

### 感知

- 视距 15m，水平视锥 ±62°（共 124°）。
- 视线用 `Raycaster` 打墙/立柱/隔断/柜体/货架/木箱/铁桶；被挡住就看不见。
- **1.0m 内贴脸感知**（不再判视锥，避免抓住瞬间"看不见"）。
- 丢失视野有 0.9s 宽限，之后才转 `SEEK`。

### 抓取条件

- 40：玩家**站着**才抓；倒地绝不抓（已切 `WANDER`）。
- 70 / 100：站着或倒地都抓。

### 寻路

- 0.5m 网格 A*，8 方向、禁止斜穿墙角；障碍按 0.42m 膨胀。
- 路径拉直（视线可达就跳过中间点）。
- 起点/终点落在障碍里会自动找最近可走格。

## 验证记录（2026-11-19）

- 速度实测：0 → 2.41、40 → 2.67、70 → 2.96、100 → 3.40 m/s（目标 2.40 / 2.70 / 3.00 / 3.435）。
- 40 级玩家倒地：`CHASE → WANDER`，0.92m 贴身但不抓。
- 70 级玩家倒地：0.95m 触发 `GRAB`。
- 70 级躲到隔断后：`CHASE → SEEK`（前往最后目击点）→ 2.6s 后 `WANDER`。
- 100 级隔墙：持续 `CHASE`，不丢失。
- 键盘/拖拽/屏幕方向键/四档按钮/倒地/重来/小地图开关全部通过；控制台 0 报错。
- `file://` 直接打开正常（图集为 dataURL，不依赖服务器）。
- 边缘清理后校验：alpha 与清理前逐像素一致，实心区 RGB 逐像素一致，洋红像素 0；纸片形状/动画未变。

## 接主游戏时

1. 把 `assets/paperbot/` 整个目录带过去，加载 `paperbot_sheet.js`。
2. 复用 `buildCharacter()` / `setFrame()` / `updateCharacter()`：广告牌只跟相机水平角，不要 `lookAt` 全姿态。
3. AI 只需替换：玩家位置、玩家速度基准、视线遮挡物数组、地面可行走网格。
4. 关掉调试可视化（视野锥/巡逻线/导航线/头顶标签/小地图），保留纸边与地面阴影。
5. 纸边 ShaderMaterial 不参与雾，远处会保留一圈暗边；不需要可移除该网格，或在 fragment 里混入雾因子。
