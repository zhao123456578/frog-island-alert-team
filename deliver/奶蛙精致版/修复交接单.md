## 3. 本轮改了什么（改 bug 前先知道现状）

### 3.1 连续接触碰撞（重点）
- `obbVsBox()`：增加 1.5 cm 接触“皮肤”（SKIN），贴墙时接触不再一帧有一帧无。
- `resolveContact()`：
  - 分离量改为真实重叠 + 2 mm，皮肤接触不再把车弹开；
  - 持续接触时法向分离速度上限 0.1 m/s（首帧保留少量回弹），消除“压进去→弹开→再压”的抽搐；
  - 同类障碍伤害/金属声/提示去重：连续贴墙只在**首次**、或**真正分开 >2.2 s**、或**法向闭合 >28 km/h 的强冲击**时才结算；物理分离/摩擦仍每帧计算；
  - `contactCooldown` 只挡重复记账，不冻结物理；
  - 左前角/右前角碰撞的偏航方向（右偏/左偏）已验证。
- 火花位置抬高到风挡视野内，低速/侧向擦碰也能看到火星。

### 3.2 碰撞提示残留
- `toast(msg, dur)` 支持停留时长：碰撞类 **1.45 s**、低速危险 1.6 s、默认 2.0 s。
- 轻微擦碰（level 0/1）不弹大提示；持续贴墙不重复刷提示。

### 3.3 低速黑屏困倦事件（重做）
- 黑屏期间 `update()` 直接 return：**物理、计时、里程全部暂停**。
- 黑屏文字：“眼前一黑——车滑到了路肩” + “**按 Space / 任意键 醒来**”，点击/触摸也能唤醒。
- 醒来：把黑屏时长从 `S.startTime` 扣掉、车摆到右车道（lateral=0.55，世界横向≈2.75 m）、psi=0、清空按键，给 `graceT=1.5`（碰撞保护）+ `dozeProtectT=8`（8 秒内不会再次睡着），提示“惊醒 · 靠边了”。
- 第二次困满 100%（normal 难度）仍直接结束“睡着了”；easy 可重复触发，这是原设计。

### 3.4 其他
- FOV 收紧并封顶：59–64°（怠速 59，高速实测 63.6）。
- 调试状态扩展：`__game.state()` 增加 `dozeT/dozeProtectT/dozeWoke/toastT/toastOn/toastText/phys.hurtGapT/phys.lastHurtTag` 等。
- 车辆密度常量未重写，本轮逐项验证达标（见验收结果）。

## 4. 已知遗留问题 / 可以继续修的点

按优先级：

1. **80 km/h 满舵怼护栏的极端瞬态**
   - 速度：80 → 瞬态最低约 16 km/h（不会停死，随后恢复）；
   - 横向位置峰值可能到 3.68（正常期望 ≤3.3），约 2–3 cm 瞬态穿插，极端情况下可能有轻微视觉穿模。
   - 相关位置：`resolveContact()` 的 `push`、`vnCap`、`S.dist/S.lateral` 分离钳制。
2. **贴墙时 `contactActive` 约一半帧为 true**
   - 原因：每帧分离 2 mm 后下一帧再贴回（SKIN=0.015）。视觉稳定、无抽搐；若想做到“每帧都 active”，可调 SKIN / push，或把“接触判定”和“分离”解耦。
3. **合成接触的提示文案**
   - `__game.contact()` 验收合成一次撞击后，底部 toast 偶尔被长台词压缩成“继续”；真实驾驶撞护栏会正常显示“撞了 · 别停”。如果要修，看 `toast()` 里长文案正则映射的优先级（`撞|擦` 应最高）。
4. **黑屏期间仍在 rAF 渲染冻结帧**（性能可接受；若想省 GPU 可在 `loop()` 里 dozing 时跳过 render）。
5. **调试残留**：`?shot&traffic` 参数仍尝试摆 3 辆车（实际 traffic 数组只有 1 辆），只影响调试截图，不影响正式游玩。
6. **追逐者主画面模型**默认是 `assets/chaser` 剪影 sprite；GLB 需要 `?chaserglb=...` 显式开启。未改动，属设计如此。

另：**线上 WorkBuddy 预览（旧 sharecode 页面）落后于仓库，不要拿线上版本覆盖本地/仓库。**

## 5. 怎么复现/自测

### 5.1 启动游戏
```bash
cd deliver/奶蛙精致版
py -m http.server 8137        # 或 node scripts/serve.mjs（仓库根目录）
# 打开 http://127.0.0.1:8137/outdoor.html
```
另一个入口 `outdoor.html?from=factory&act=3` 已验证可正常加载；`index.html` 是工厂/院子流程入口。

### 5.2 重点手测步骤
1. 连续开 60 秒，前方最多 1 辆动态车；
2. 开 1.5 km 不会出现循环车流/车队；
3. 20–30 km/h 斜擦护栏 → 只轻微掉速、继续滑行、有火星；
4. 50–70 km/h 侧擦 → 火花/甩尾/短震，不会停死；
5. 80 km/h 正撞 → 明显减速，短时间后可继续开；
6. 持续贴墙 3–5 秒 → 不抽搐、不弹飞、不穿模、提示只出现一次；
7. 低速后视镜出现模糊车灯/黑影 + 红边“不要停”；
8. 困意满 100% 黑屏 → 明确提示按键、距离和计时暂停 → Space 醒来在路肩，短时间不重复触发；
9. 浏览器控制台无报错。

### 5.3 页面内调试 API（F12 控制台）

```js
__game.state()                 // 全量状态（含 veh 车辆密度 / phys 碰撞 / doze / toast）
__game.set({dist:640,speed:22.2,psi:0,lateral:1.0})   // 直接摆位/给速度
__game.tick(1/60)              // 推进一帧物理（可循环，确定性测试）
__game.contact({nx:-0.95,nl:0.10,mass:2800,relv:0})   // 合成一次接触（走同一套求解器）
__game.doze() / __game.wake()  // 触发/唤醒黑屏困倦事件
__game.toastInfo()             // 当前提示文本与剩余时长
__game.camera / __game.scene / __game.traffic        // 场景对象
__game.shot('名字')            // 渲染当前帧并 POST 保存到服务端 _shots/
```
