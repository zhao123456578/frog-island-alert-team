奶蛙：午夜奶厂 + 夜班归途 · 整合试玩 Demo v4.4（2026-11-23）

启动
1. 将 ZIP 完整解压到任意文件夹，不要直接在压缩软件中运行。
2. Windows 10/11 x64 双击“启动试玩.bat”，浏览器会自动打开封面主菜单（start.html）。
3. 保持启动窗口打开；关闭窗口或 Ctrl+C 可停止本地服务。
4. 已附带 Node 运行时，无需安装 Node/Python，也不依赖联网。
5. 若浏览器没有自动打开，请复制启动窗口中的本地地址；不要双击 HTML。

游戏开始（v3 新增，v4.4 保留）
封面主菜单：
  开始游戏      —— 进第一幕 · 醒奶区
  关卡目录      —— 六格目录：三幕 + 停车场 + 夜班归途 + 开发者模式
  开发者模式    —— 直接进第一幕并打开调试面板
游戏内选关目录（index.html）：
  三张章节卡（第一/二/三幕）+ 停车场 + 夜班归途，可点卡片选中，再点“开始 …”进入。
游戏内暂停菜单（Esc / P）：
  “回选关目录”回到选关页，“返回主菜单”回到封面。

完整流程
封面 → 开始游戏 → 第一幕 → 三瓶合格封盖 → 下班或留下调查 → 员工出口离厂
→ 停车场走到车的左侧驾驶门 → E 上车 → 夜班归途。
工厂的离厂选择会传到驾驶结算小票。想快速看驾驶段，可从封面“关卡目录 → 夜班归途”直接进。

操作
工厂：WASD 移动，鼠标环视，E 交互，左键或 J 挥击，F 手电，空格装死，B 背包，Esc 释放鼠标。
  挥击：右手挥击，随时可挥——面前没有目标也能对着空气挥；贴身且朝向对方时才会打中。
  孙笑川 5 下打晕（晕 6 秒，醒来更生气），主角 2 下就倒地。
灌装工位（封盖小游戏）：空格 封盖 · F 偷吃一瓶 · R 离开工位。
  划线来回扫（1.05 格/秒），浅绿色区间只有 14%——比上一版难一倍。
停车场：WASD 移动，鼠标环视，到左侧驾驶门按 E——按 E 的瞬间就锁住指针，
  拉门、坐进驾驶位、黑场这整段过场画面上都没有光标。
驾驶：W 油门，S 刹车，A/D 转向，C 切换视角，R 雨刷，鼠标环视。
  夜班归途（outdoor.html）正常进入时先显示标题和难度选择，默认“标准”，可切“轻松”；
  点击“发动引擎”后才发车并尝试锁定鼠标。只有显式 ?direct 才自动快速进入。
对话字幕逐字出现；按住 E 连续推进（不用点鼠标，也不要一格一格点）。
声音需要第一次点击或按键解锁；建议使用耳机。不要切换浏览器标签页来等待剧情。
鼠标：工厂和停车场进游戏后不会出现光标——除了指针锁定，还在游玩状态下用 CSS 整页隐藏指针
  （预览 iframe 里拿不到锁定时也不会飘箭头），按任意键或点一下画面就锁定，Esc 释放；
  只有暂停菜单 / 背包 / 开发者面板 / 结局才把光标放出来。
  驾驶段 v4.4 起同样支持指针锁定：点击画面后直接移动鼠标即可环视（看后视镜/侧窗不用按住左键），
  Esc 释放，再点画面可重新锁定；浏览器或预览 iframe 拒绝锁定时自动回退成“按住左键拖动环视”。
  结局会释放鼠标锁定并收起锁定提示。

v3 变化
- 右手挥击重做：蓄力（握拳后收）→ 横扫（张手过身体中线）→ 收手，带甩腕、躯干带动、手指开合，
  横扫时有一道奶白色残影；命中帧与动画对齐（0.16s）。
- 奶瓶手电改挂左手，右手空出来打人；挥击时左手会往后让位，不再两只手撞在一起。
- 空挥：面前没有目标也能挥，只有真正扫到人身上才结算伤害与击退。
- 挥击与交互不再抢左键：准星对着可交互物且不是贴身战 → 交互；其余情况 → 挥击。
- 触屏 / 小窗预览新增“拳”按钮，键盘 J 也能挥。
- 游戏开始目录：封面主菜单 + 关卡目录 + 游戏内选关（含停车场、夜班归途入口）。
- 夜班归途更新到带血雾 / 挡风玻璃血糊 / 副驾驶结局的版本。
- 树换成建模树：锥形树干 + 分枝 + 9~12 片叶簇卡（canvas 画的碎叶团，不是纯色多边形），
  每棵 ~90 面、按材质合并成 2 个 draw call；三个色差变体轮换，路边密度提高约 40%。
- 挥击风声换成《我的世界》原版横扫攻击音效（Sweep_attack1，0.21 秒），
  裁掉前导静音、峰值归一，起手即响；每次只是 ±2% 的音高微随机。
- 停车场补上 PS1 后期：场景先渲到 RT，再量化到 12 级亮度 + 4×4 Bayer 抖动 +
  扫描线 + 桶形畸变 + 暗角，模型顶点按 160×90 屏幕格吸附（PS1 那种轻微抖动）。
- 停车场内部分辨率从 640×360 提到 960×540，糊的问题解决；PS1 质感交给量化/抖动，不再靠低分辨率。
- 地面闪烁修复：片元噪声从"按时间变化"改成固定空间噪点；大平面不再做顶点吸附
  （否则整片地面的插值深度会抖）；地面纹理改三线性 + 各向异性，贴地标线/水洼抬高并加 polygonOffset。
- 停车场围栏外补了一层建模树（锥形干 + 分枝 + 叶簇卡，canvas 碎叶贴图，按材质合并），
  场地不再是一圈盒子对着空天。

v4.4 变化
- 修复“和工位奶蛙聊完天，光标没了、鼠标也转不动视角”：对话 / 工位 / 躲藏这些只挡输入、
  不需要点鼠标的状态不再释放指针锁定，聊完立刻能继续转头；只有暂停菜单 / 背包 / 确认框 /
  结局才解锁，关掉后再自动锁回来。
- 修复 (x 7.13, y 1.10, z 5.92) 卡住：同事 NO.07 去座椅的路上，碰撞体把玩家顶进墙角。
  它的碰撞体现在只给 NPC 寻路用，不再推玩家。
- 开发者模式改成“光标点击移动”：不再锁指针、不再鼠标一拖镜头就跟着转；
  左键点场景把相机传送到点击位置（点地面就站到地面），右键拖拽才环视，WASD 照常移动。
- 回档驾驶段：从停车场上车后，黑场一亮直接出现在出厂之后的公路上（和从菜单进“夜班归途”
  看到的是同一段路）。厂区停车场 / 停车带 / 柱网 / 窄门 / 厂门不再出现在驾驶场景里。
- 停车场的步行、走到驾驶门、拉门、坐进驾驶位、淡出仍然保留在 yard 里，过场本身没有删。
