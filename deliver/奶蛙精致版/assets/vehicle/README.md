# 室外驾驶车辆

当前默认车辆选用 `soviet_lowpoly_vehicles` 中的 Buhanka（UAZ-452）救护车版本：

- `buhanka_ambulance.obj`：带顶部警灯的 94 三角面模型。
- `buhanka_skoraya_albedo.png`：救护车配色像素贴图。
- 来源：OpenGameArt 的 “Pack of extremely low poly soviet vehicles in pixel art style”
- 作者：MadMedicSoft
- 许可：CC0

`ambulance.glb`、`sedan.glb`、`truck.glb`、`van.glb` 是之前保留的备选素材。

通过 `?carglb=assets/vehicle/ambulance.glb` 可以临时切回 GLB；
通过 `?carobj=assets/vehicle/buhanka_ambulance.obj` 可显式指定 OBJ。
`?carglb=0` 会禁用 GLB 并回退到程序化车壳。
